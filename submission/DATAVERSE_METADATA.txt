Description (Text):
Replication package for Balke, Bonhomme and Lamadon, "Indirect Variational
Inference: Applications to Earnings Dynamics," Journal of Labor Economics.
The paper evaluates variational inference (VI) in models of earnings dynamics
and introduces indirect variational inference (IVI), which treats VI as an
auxiliary model and corrects the bias induced by the variational
approximation. The package contains the Python code (PyTorch) for all
simulations, the estimations on PSID earnings data, and the figures and
tables; a pinned software environment; the estimation results (JSON bundles)
from which every figure and table can be rebuilt in about two minutes
without data or a GPU; and a README (PDF and Markdown) following the Social
Science Data Editors template.
The empirical application uses the PSID household panel prepared by
Blundell, Pistaferri and Preston (2008), ICPSR 210782 V2
(https://doi.org/10.3886/E210782V2), which cannot be redistributed under the
PSID Conditions of Use. It is not included; the README explains how to
obtain it free of charge and run the full replication.

         the folder paths. That is the usual choice: replicators can browse
         and download single files. (To store the package as one zip
         instead, zip it once more, "double-zip", before uploading.)
         Check after upload that README.pdf sits at the top level.
